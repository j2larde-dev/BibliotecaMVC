BibliotecaMVC

Aplicación web desarrollada en ASP.NET MVC como parte del curso Programación Web II (UEES).
El proyecto implementa un catálogo de autores con vistas dinámicas, modelos fuertemente tipados y renderizado de datos desde controladores.

1. TECNOLOGÍAS UTILIZADAS
ASP.NET MVC 5 / .NET Framework
C#
Razor Views
Bootstrap
Git & GitHub
Visual Studio 2022

2. ESTRUCTURA DEL PROYECTO
Models/
Contiene las clases de dominio, incluyendo el modelo Autor.

Controllers/
Controlador principal AutorController que gestiona la lógica del catálogo.

Views/
Vistas Razor para mostrar la información de autores.

3. FUNCIONALIDADES PRINCIPALES
Listado de autores con:
Nombre y apellido
Nacionalidad
Fecha de nacimiento (formato corto dd/MM/yyyy)
Estado (Activo / Inactivo)

Renderizado dinámico desde ViewBag o modelos.
Formato de fecha personalizado.

4. CÓMO EJECUTAR EL PROYECTO
Clonar el repositorio:
git clone https://github.com/j2larde-dev/BibliotecaMVC.git

Abrir la solución en Visual Studio 2022.
Restaurar paquetes NuGet si es necesario.
Ejecutar con IIS Express.
